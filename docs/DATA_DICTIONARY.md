# Synthetic event data dictionary

Generated by `ml/generate_synthetic.py`; every output row represents a synthetic queue prediction observation. Rows have a fixed seed and a UTC arrival timestamp. The generated queue observations are synthetic, not patient records.

| Field | Type | Meaning |
|---|---|---|
| `arrival_at` | ISO-8601 datetime | Synthetic arrival timestamp; use for chronological train/test ordering |
| `department` | string | Synthetic service area |
| `patients_ahead` | integer | Number waiting ahead at prediction time |
| `available_staff` | integer | Staff available at prediction time, always at least one in this generator |
| `occupied_staff` | integer | Busy staff count at prediction time |
| `typical_service_minutes` | number | Typical service-duration feature available at prediction time |
| `hour` | integer | Local synthetic hour (08-17) |
| `is_appointment` | 0/1 | Visit appointment indicator |
| `actual_wait_minutes` | number | Synthetic realized wait outcome; training target only |

`ml/train.py` sorts by arrival time, trains the first 80% and evaluates on the later 20%. Patient-level leakage is not applicable because generated rows are independent synthetic events; do not reuse this assumption for real longitudinal patient observations.
